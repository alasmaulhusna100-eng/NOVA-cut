# NovaCut AI Video Studio (PWA)

ব্রাউজারেই চলা ভিডিও এডিটর। সব প্রসেসিং আপনার ফোনেই হয়, কোনো ব্যাকএন্ড লাগে না। Android-এ Chrome দিয়ে ইনস্টল করলে WebAPK হিসেবে অ্যাপের মতো চলে।

## ফিচার
- একাধিক ভিডিও ইমপোর্ট ও ক্রমানুসারে জোড়া লাগানো
- ট্রিম, স্প্লিট, ডুপ্লিকেট, ক্রম বদল, স্পিড (0.25×–3×), ভলিউম, ক্রপ/ফিট
- ৮টি ফিল্টার + উজ্জ্বলতা/কনট্রাস্ট/স্যাচুরেশন
- টেক্সট ও ক্যাপশন (বাংলা সাপোর্ট), SRT এক্সপোর্ট
- **স্মার্ট নীরবতা কাটা**: অডিও বিশ্লেষণ করে নীরব অংশ বাদ দেয় (অফলাইন)
- **স্ক্রিপ্ট → অটো ক্যাপশন**: স্ক্রিপ্ট ভিডিওর দৈর্ঘ্য অনুযায়ী ভাগ হয়
- **AI স্ক্রিপ্ট লেখক**: যেকোনো OpenAI-compatible API (আপনার নিজের key)
- 16:9, 9:16, 1:1, 4:5 এবং 480p/720p/1080p এক্সপোর্ট (MP4 বা WebM)
- গ্যালারি থেকে "Share → NovaCut" (Android WebAPK-এ)

## চালানো
PWA ইনস্টলের জন্য HTTPS লাগে (localhost বাদে)।

**লোকালি টেস্ট:** এই ফোল্ডারে `python3 -m http.server 8080` চালিয়ে `http://localhost:8080` খুলুন।

**ফ্রি হোস্টিং (যেকোনোটি):**
- Netlify: ফোল্ডারটি drag-and-drop করুন (app.netlify.com/drop)
- GitHub Pages, Cloudflare Pages, Vercel

## Android-এ ইনস্টল
1. হোস্ট করা লিংক Chrome-এ খুলুন
2. মেনু (⋮) → **Install app** / **Add to Home screen**
3. Chrome নিজেই WebAPK বানিয়ে ইনস্টল করবে

## Play Store বা নিজস্ব APK
হোস্ট করার পর [PWABuilder](https://www.pwabuilder.com) এ URL দিন, Android package ডাউনলোড করুন। অথবা Bubblewrap (TWA) ব্যবহার করুন।

## সীমাবদ্ধতা (সৎভাবে)
- এক্সপোর্ট রিয়েল-টাইমে হয়: ১ মিনিটের ভিডিও ≈ ১ মিনিট। স্ক্রিন অন রাখুন।
- প্রজেক্ট সেভ হয় না (ব্রাউজারে ভিডিও ফাইল স্থায়ীভাবে রাখা হয় না); পেজ রিলোড করলে ক্লিপ চলে যায়।
- ফিল্টার `ctx.filter` ব্যবহার করে: Chrome/Edge/Android Chrome-এ চলে, iOS Safari-তে নয়।
- AI ভিডিও জেনারেশন (টেক্সট→ভিডিও) নেই; "AI" অংশ হলো নীরবতা শনাক্তকরণ ও স্ক্রিপ্ট লেখা। চাইলে পরে Runway/Replicate API যুক্ত করা যায়, তবে তার জন্য সার্ভার-সাইড প্রক্সি দরকার।
- API key ব্রাউজারের localStorage-এ থাকে। শেয়ার্ড ডিভাইসে ব্যবহার করবেন না।

## ফাইল স্ট্রাকচার
```
index.html            UI
style.css             ডিজাইন
app.js                এডিটর ইঞ্জিন (প্লেব্যাক, টাইমলাইন, ফিল্টার, এক্সপোর্ট, AI)
sw.js                 অফলাইন ক্যাশ + share target
manifest.webmanifest  PWA/WebAPK ম্যানিফেস্ট
icons/                192, 512, maskable আইকন
```
